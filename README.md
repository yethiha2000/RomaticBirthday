# Romantic Birthday Website

Premium romantic birthday experience built with React, Vite, Tailwind CSS, Framer Motion, Lucide, and canvas-confetti.

## Setup

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Personalize

1. Put your photos in `public/images/`.
2. Use these filenames:
   - memory-01.jpg
   - memory-02.jpg
   - memory-03.jpg
   - memory-04.jpg
   - memory-05.jpg
   - memory-06.jpg
3. Put your music at `public/music/romantic.mp3`.
4. Put `Pyidaungsu.ttf` in `public/fonts/`.
5. Edit the Myanmar/English messages in `src/components/Hero.jsx`, `LoveMessage.jsx`, and `Surprise.jsx`.

## Vercel

Push the project to GitHub and import the repository into Vercel.

Framework: Vite
Build command: `npm run build`
Output directory: `dist`
Install command: `npm install`
